# Student Result Calculator

## 📌 Project Overview

Student Result Calculator is a simple application designed to calculate a student's total marks, average/percentage, and result based on the marks entered for different subjects.

## 🎯 Objectives

- Calculate students' total marks.
- Calculate average/percentage.
- Display the student's result.
- Make result calculation simple and easy to use.
- Reduce manual calculation errors.

## ✨ Features

- Enter student details.
- Enter subject-wise marks.
- Calculate total marks automatically.
- Calculate percentage.
- Display the final result.
- Simple and user-friendly interface.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## ⚙️ How It Works

1. Enter the student's name.
2. Enter marks for each subject.
3. Click the calculate button.
4. The system calculates the total and percentage.
5. The final result is displayed.
